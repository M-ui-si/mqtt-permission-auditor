# 架构与范围

状态：阶段 0–4 已完成，新语义本地 Broker 复验见 [阶段 4 证据](evidence/stage4-integration-20261008.md)。2026-10-09 可复现部署已在 Docker Desktop 29.8.0 实际启动并完成健康检查及固定案例审计；隔离 AGH profile 已安装面板最终源码。当前工作区就是最终成品，不安排平移到第二套 AGH。真实 Agnes 会话中的工具轨迹与报告画面、比赛演示材料尚未完成，最新状态见 [进度](progress.md)。历史证据仍按当时语义保留。

## 首个场景

Mosquitto → EMQX 文件 ACL 迁移验收。两端 Broker 版本、认证方式、ACL 配置与默认决策已固定并实测（见 [环境版本记录](environment-versions.md) 与 [阶段 1 证据](evidence/stage1-acl-difference-20261007.md)）。

不在首版覆盖云平台 API、数据库授权源、生产环境扫描或全自动迁移。发现差异后可生成配置副本中的修复建议，实际修改与复测范围另行明确。

## 两个入口，共用验证器

```text
本地工程师 / CI → CLI ──────────────────────┐
                                            ↓
Agnes → AGH 规划与工具调用 → AGH 插件 → 核心验证器
                                            ↓
                              本地隔离 Broker + 合成夹具
                                            ↓
                              结构化观测、差异与业务判定
                                            ↓
                      CLI 报告 / AGH 反馈、复测、总结和轨迹
```

核心验证器负责确定性判断，可独立使用（`core/`、`cli/run-audit.mjs` 已实现）。AGH 插件只是受控适配层（`plugins/agh/mqtt-audit-tools` 的基础工具闭环历史证据见 [阶段 3 证据](evidence/stage3-agh-plugin-20261007.md)）；比赛中的规划、调用、反馈、验证必须由实际 AGH 会话完成。当前 AGH 会话的面板与本次报告联动仍待验收；本项目不安排第二套 AGH 平移验证。

## 验收维度

| 维度 | 要回答的问题 |
| --- | --- |
| 权限扩大 | 源端不允许的操作是否在目标端变为允许？ |
| 业务受损 | 源端允许且业务仍需要的操作是否被目标端拒绝？ |
| 业务要求 | 迁移前后是否分别满足明确的允许和禁止要求？ |

源端和目标端同样允许危险操作时，差异检查可能没有发现变化，但业务要求仍然失败。业务有意调整权限时，应记录变更意图，区分已批准变更与非预期变化。

## 结果与证据

每项要求独立标注“通过、失败、无法判定”，报告列出原因、规则与配置、版本、测试身份、动作、主题、观测及证据引用。汇总采用最坏状态优先（失败 > 无法判定 > 通过），已知失败不被未知项冲掉；机器可读 JSON 与人读报告已实现（`core/report.mjs`、`cli/run-audit.mjs`）。

发布成功、订阅获准和消息实际送达分别观测；允许判定的主证据是见证订阅者实际收到消息，拒绝判定仅在存在主题级明确拒绝证据（SUBACK 0x80）时报出。CONNACK 4/5 属连接建立阶段拒绝，身份未能建立连接，不代表主题 ACL 拒绝；MQTT 3.1.1 下发布被拒无协议级证据——两者与"收到 PUBACK 但未送达"一律判"无法判定"。断连、超时、服务未就绪或不支持的语法同样意味着无法判定。

有限测试仅证明列出的条件和范围，不宣称全主题空间或所有身份上的语义等价。通配符、规则顺序、默认决策等覆盖边界需要明确记录。

## 执行边界与迁移安装

只使用本地实例和合成数据，Broker 地址固定为数字回环 `127.0.0.1`（core 与 CLI 双层校验，拒绝其他任何主机地址）。插件接收受控的任务、夹具和实例标识，不接收任意 Shell、文件路径、URL 或模型参数。Compose 使用源/目标两个不互通的 bridge 网络、关闭 outbound IP masquerading、只绑定回环 MQTT 端口，并限制资源；运行中的容器仍具有 bridge 网络接口，因此项目验证逻辑只访问本地 Broker，不声称容器无法路由到任何外部或宿主地址。

最终交付包含插件包、版本要求、本地夹具和部署说明。当前交付范围固定在本工作区及其隔离 `local-dev` AGH profile，不搬运 AGH home、会话、缓存或凭据；跨环境安装不属于本项目待办，也不据此声称通用可移植性。
