## AGH 作用（可直接粘贴）

> AGH（Agnes Harness）是整个验收闭环的宿主：项目以插件 mqtt-audit-tools@0.3.0 接入，注册 4 个受控工具（mqtt_audit_list_cases / mqtt_audit_prepare_run / mqtt_audit_run_check / mqtt_audit_read_result，另有默认关闭的可选建议工具 mqtt_audit_plan_next）、一个会话 Skill（mqtt-migration-audit，用户只说目标即可）和右栏"过程面板"（双端拓扑、实时事件流、历史回放、复测对比、独立健康监测）。比赛任务的核心规划、工具调用、结果解释与复测安排全部在 AGH Web 会话内完成；插件不提供 Shell、任意路径读取、任意网络访问或模型调用，工具只接受固定案例集与固定本地实例标识，面板发起/复测也经由会话 prompt 入口。会话轨迹可用官方 `agh export` 导出完整审计。
